# Symbol coverage

Generated by `tools/coverage_report.gd` from `tests/golden/coverage.json` (`tools/export/coverage.mjs`). Do not edit by hand.

The symbol lists are the ones milsymbol's own test suite walks (`test/number-sidc.js`): every point main
icon, modifier 1 and modifier 2 of each symbol set in the standards data packages `mil-std-2525` (2525D),
`milstandard-e` (2525E) and `stanag-app6` (APP-6D). Each SIDC is rendered by milsymbol 3.0.5 and by
godot-milsymbol; *matches* counts symbols whose SVG, size, anchor and validity are the same.
*Valid in milsymbol* counts the symbols milsymbol itself can draw; the rest are drawn as an unknown icon
by both libraries. Lines and areas (multipoint control measures) are not part of these lists; see
`docs/control-measures.md`.
