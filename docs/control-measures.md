# Control measures

Generated by `tools/control_measures_report.gd`; edit the tool, not this file.

Multipoint control measures (tactical graphics) are symbol set 25 lines and areas of MIL-STD-2525D/E and
APP-6D. Point control measures (checkpoints, contact points, mines, ...) are ordinary point symbols drawn by
`MilSymbol` like units (see `docs/coverage.md`).

```gdscript
var shape := MilGraphic.build("10032500001403000000", PackedVector2Array([Vector2(0, 0), Vector2(300, 20)]),
		{"T": "BLUE"})  # friendly phase line "PL BLUE"
MilGraphicRenderer.draw(canvas_item, shape)  # inside _draw(); or MilGraphicRenderer.to_svg(shape)
```

Or add a `MilGraphic2D` node, or `TacticalMap2D.add_graphic()` with geographic points.

## Rules

- **Points** are in a 2D plane with y growing downwards (screen pixels for `MilGraphic.build`, longitude /
  latitude for `TacticalMap2D`). Lines run from the first to the last point; areas are closed automatically.
- **Axis of Advance**: the arrow tip first, then the centreline to the rear, then one point on the edge of the
  arrowhead: its distance from the axis sets the arrowhead half width (the shaft is half as wide) and its
  distance behind the tip the arrowhead length. **Direction of Attack**: the tip first.
- **Rectangular fire areas**: two points on the centre line and `AM` = width. **Circular**: the centre and
  `AM` = radius. **Corridors**: the centre line and `AM` = width. `AM` is in point units (`MilGraphic`) or
  metres (`TacticalMap2D`).
- **Amplifiers**: `T` (unique designation), `T1`, `W` / `W1` (date-time group, from / to), `H`, `X` / `X1`
  (altitudes).
- **SIDC**: standard identity 5 / 6 draws the hostile colour and, where the standard uses it, "ENY"; status 1
  (planned / anticipated) dashes the outline; the feint / dummy amplifier draws a dashed "^"; the echelon is
  shown on boundaries. APP-6D subtypes such as 140104 "FLOT, enemy suspected" use the same rules.
- **Colours** (`MilGraphicRenderer.PALETTE_LIGHT_MAP`): friendly black, hostile red, neutral green, unknown
  yellow; obstacles and mines are green whatever the affiliation. `PALETTE_DARK_MAP` is for dark map
  backgrounds. Text sizes and the pixel sizes of decorations (teeth, half circles, arrowheads) scale with the
  `scale` option.
- **Geometry** is our own; shapes and several pixel constants follow the Mission Command renderer mil-sym-ts
  (Apache-2.0), which was read as a reference. There is no MIT reference renderer to compare against, so the
  tests check geometric rules and keep regression SVGs (`tests/golden/graphics.json`); see the gallery demo
  (`demo/graphics_gallery.tscn`).

|---|---:|---:|---:|
| MIL-STD-2525D | 271 | 76 | 195 |
| MIL-STD-2525E | 302 | 73 | 229 |
| APP-6D | 286 | 93 | 193 |

Codes without their own geometry are drawn as a plain line or area with the `T` amplifier, so every
code of the three tables produces something sensible.
